# مسار المستخدم — كل زر وشنو يصير بعده

هذا الملف هو "خريطة" التطبيق: كل شاشة، كل زر، وشنو المفروض يطلع للمستخدم بعد ما يضغطه. استعمله كمرجع للتصميم وللتطوير وللاختبار.

> المصطلحات: **الوكيل** = Covo (اسمه قابل للتغيير). **الخيط** = محادثة واحدة مستمرة. **الموضوع (Topic)** = عنوان صغير يجمع الرسائل (مثل "Dubai showroom launch"). **البطاقة** = عنصر تفاعلي داخل الخيط (موافقة، بريد، ملف).

## 0) أول تشغيل (Onboarding)

| الخطوة | المستخدم يشوف | يضغط | النتيجة |
|---|---|---|---|
| 1. ترحيب | الكرة (Orb) + "Meet Covo." + اختيار اللغة English / العربية | **العربية** | الواجهة تنقلب RTL فوراً |
| | | **Get started** | ينتقل لخطوة الاسم وكلمة السر |
| 2. من أنت | حقول: الاسم، كلمة السر، تأكيدها (النسخة المستقلة بالمتصفح/الهاتف ما تحتاج كلمة سر) | **Continue** (يتفعّل فقط إذا الاسم موجود وكلمة السر ≥ 6 ومتطابقة) | خطوة اختيار "الدماغ" |
| 3. الدماغ | 3 خيارات: Claude / نموذج محلي / Demo | **Claude** | يظهر حقل مفتاح API (اختياري الآن) |
| | | **Local** | يظهر Base URL + اسم النموذج (افتراضي Ollama) |
| | | **Try the demo first** | التطبيق يشتغل بقصة تجريبية جاهزة (بدون نموذج) |
| 4. الشكل | شبكة ثيمات | الضغط على ثيم | يتطبق على الصفحة فوراً (معاينة حية) |
| | | **Continue** | يُنشأ الحساب، تُحفظ الإعدادات، يُفتح جلسة (cookie) |
| 5. جاهز | "You're set, Sara." + 4 نصائح (Chat / Tasks / Make / Devices) | **Open Covo** | يدخل الدردشة. في وضع Demo: بعد ~1.5 ثانية الوكيل يبدأ يكتب لوحده (Dubai showroom launch) |

**الدخول لاحقاً:** شاشة كلمة السر فقط → **Sign in**. خطأ = "Wrong password". 5 محاولات خاطئة = قفل مؤقت (دقيقة فأكثر).

## 1) الشاشة الرئيسية — الموبايل

```
┌────────────────────────────────┐
│ (≡)          ( ◉○ )         (S)│  ← رأس شفاف، الرسائل تمر تحته
│                                │
│ ╭ ☑ Morning brief              │  ← وسم الموضوع (Topic tag)
│ ┌──────────────────────────┐   │
│ │ • (◌ Hiring): …          │   │  ← فقاعة الوكيل (رمادي)
│ └──────────────────────────┘   │
│               ┌────────────┐   │
│               │ Go ahead.  │   │  ← فقاعة المستخدم (خوخي)
│               └────────────┘   │
│ ● ● ●                          │  ← نقاط الكتابة
│ [ Go ahead. ] [ … ]            │  ← اقتراحات سريعة (في الـDemo)
│ ┌ + Message          🎤  (≋) ┐ │  ← صندوق الكتابة
│      [ Chat | Tasks | Make ]   │  ← شريط التبويبات
└────────────────────────────────┘
```

### الرأس
| العنصر | الضغط | النتيجة |
|---|---|---|
| **≡ (القائمة)** | ضغطة | درج جانبي من اليسار (اليمين في العربي): بحث، Chat/Tasks/Make مع عداد "يحتاجك"، المواضيع مع أيقونة حالتها، الروتينات، الأجهزة (عدد المتصل)، الإعدادات. في الـDemo يظهر صندوق "Demo mode → Connect a model". |
| **الكرة (Orb)** — كرة مرجانية يدور حولها حلقة حبر ونقطة "شريك" | ضغطة | إذا في شي يحتاجك → يفتح تبويب Tasks. إذا لا → يرجع للدردشة وينظف الفلتر. (على الديسكتوب: يفتح/يسد لوحة Overview) |
| | شكلها | **idle** الحلقة تميل بهدوء · **thinking** الحلقة ترسم نفسها · **writing** الكرة تتمايل والحلقة تبهت · **working** النقطة تدور حول الكرة (يستعمل أدوات) · **waiting** نبض (ينتظر موافقتك) · **listening** تكبر مع صوتك |
| **S (الحساب — أول حرف من اسمك)** | ضغطة | ورقة سفلية: الاسم + النموذج، تبديل سريع فاتح/داكن/النظام، اللغة EN/ع، مفتاح Developer، Settings، Install app (إذا متاح)، Sign out |

### الخيط (Chat)
| العنصر | الضغط | النتيجة |
|---|---|---|
| **وسم الموضوع** (☑ Morning brief) | ضغطة | يفلتر الخيط على هذا الموضوع فقط + شريط أعلى فيه زر ✕ لإلغاء الفلتر |
| **رقاقة داخل النص** (◌ Hiring) | ضغطة | نفس الفلترة على الموضوع المذكور. لون الأيقونة = الحالة: أزرق دوّار (قيد التنفيذ) · برتقالي (يحتاجك) · ✓ (منجز) |
| فقاعات الوكيل | — | كل فقرة = فقاعة. تظهر واحدة واحدة مع نقاط كتابة بينها (يمكن إطفاؤه من Appearance) |

### بطاقة الموافقة (مثال: $480.00 Trade license renewal)
| الحالة | يظهر | الضغط | النتيجة |
|---|---|---|---|
| معلّقة | المبلغ + العنوان + "Expires in 10 min" + سطر التفاصيل › + **Approve** (أسود) + **Not now** | **Approve** | الزر يصير "…"، البطاقة تتحول إلى شارة خضراء **Paid** (أو Approved)، الأزرار تختفي، الكرة تصير working، ثم الوكيل يكمل الشغل ويكتب ("Paid. Next up is the fit-out inspection…") |
| | | **Not now** | شارة رمادية **Declined**، الوكيل يُبلّغ ويعدّل خطته بدون ما ينفذ |
| | | سطر التفاصيل › | يفتح/يسد تفاصيل الأداة (الاسم + المدخلات JSON) والنتيجة بعد التنفيذ |
| انتهت المهلة | شارة **Expired** | — | يُسجل للوكيل بالدور القادم |

> الموافقات تأتي من نوعين: (1) الوكيل طلبها صراحة (دفع، توقيع، حجز)، (2) أداة حساسة حسب جدول الموافقات (أمر طرفية، كتابة ملف، إرسال بريد…). في النوع الثاني، الضغط على Approve **ينفذ الأداة فعلاً** ثم يرسل النتيجة للوكيل.

### بطاقة الملف (Artifact) — Seed deck / Atlas meeting prep / Lumen Daily
| العنصر | الضغط | النتيجة |
|---|---|---|
| المعاينة أو العنوان أو › | ضغطة | عارض بملء الشاشة: العنوان بالوسط + ✕، شريط أدوات (نسخ سابقة، تثبيت، فتح بتبويب جديد، تنزيل، حذف)، وتحت: حقل **Ask for changes…** |
| 📌 تثبيت | ضغطة | يتلوّن بلون التمييز، الملف يصعد لأعلى تبويب Make وقائمة Pinned |
| Ask for changes → إرسال | | تُرسل رسالة للوكيل: `About "Lumen Daily" (artifact …): <طلبك>`، العارض يُغلق، الوكيل يحدّث الملف (نسخة جديدة v2) وتظهر بطاقة "Updated" |

### بطاقة البريد (Email)
| العنصر | الضغط | النتيجة |
|---|---|---|
| ⧉ نسخ | | ينسخ To/Subject/Body للحافظة + تنبيه "Copied" |
| ✎ تعديل | | الحقول تصير قابلة للتحرير، الأيقونة تصير ✓ (حفظ) |
| **Send** | إذا SMTP مضبوط | يُرسل فعلياً، البطاقة: "✓ Sent" |
| | إذا SMTP غير مضبوط | يفتح تطبيق البريد عندك (mailto) جاهز بالنص، البطاقة: "✓ Sent" |
| **Not now** | | "✕ Dismissed"، الوكيل يعرف بالدور القادم |

### صندوق الكتابة
| العنصر | الضغط | النتيجة |
|---|---|---|
| **+** | | اختيار ملفات (صور/PDF/نص/كود حتى 25MB). تظهر كرقاقات فوق الصندوق مع ✕. الصور تُرى للوكيل (رؤية)، PDF يُقرأ، النصوص تُضمّن |
| لصق صورة / سحب وإفلات | | نفس الإرفاق |
| **🎤** | | إملاء صوتي (يتحول للأحمر وينبض)، الكلام يُكتب بالصندوق. ضغطة ثانية توقف |
| الزر الأسود | فارغ + الوكيل خامل | أيقونة موجة **≋** → **وضع الصوت** (شاشة كاملة: كرة كبيرة تستمع، تُرسل تلقائياً عند السكوت، تقرأ الرد بصوت، ثم تستمع مجدداً) |
| | فيه نص | سهم **↑** → إرسال. على الديسكتوب Enter يرسل و Shift+Enter سطر جديد |
| | فارغ + الوكيل يشتغل | مربع **■** → إيقاف الدور الحالي فوراً |
| اقتراحات سريعة | ضغطة | تُرسل كرسالة مباشرة |

## 4) الديسكتوب (≥ 900px أو مفروض من الإعدادات)
- **يسار:** الكرة + الاسم + شارة Demo، بحث (`/`)، Chat/Tasks/Make، المواضيع، الروتينات (+ لإضافة)، الأجهزة، Settings (`,`)، صفك الشخصي (يفتح ورقة الحساب).
- **وسط:** نفس الخيط بعرض مريح (780px) والكرة بالأعلى.
- **يمين:** لوحة **Overview** (أعداد، موافقات معلقة، يحتاجك، قيد التنفيذ، المثبّت). تتبدل إلى **عارض الملف** أو **تفاصيل المهمة** عند فتحها. زر ▯ أعلى اليمين يفتح/يسد اللوحة.
- اختصارات: `1/2/3` التبويبات، `,` الإعدادات، `/` البحث، `Esc` إغلاق.

## 5) الإعدادات (14 قسم)
موبايل: قائمة → صفحة القسم (زر ‹ رجوع). ديسكتوب: نافذة بقسمين.

| القسم | أهم الأزرار والنتيجة |
|---|---|
| **Profile** | لون الصورة، الاسم (يدخل في System prompt)، البريد، اللغة (العربية = RTL)، المنطقة الزمنية، **اسم الوكيل** |
| **Appearance** | 11 ثيم (يتطبق فوراً على كل الأجهزة)، لون تمييز مخصص، Auto/Mobile/Desktop، الكثافة، حجم الخط، نوع الخط، استدارة الفقاعات، حركة الكرة، إظهار الفقاعات واحدة واحدة، الوقت، تقليل الحركة |
| **Model & provider** | Claude / OpenAI-compatible / Demo. مفتاح API (مخفي، يُعرض آخر 4 أحرف)، النموذج + تحميل القائمة من حسابك، effort للدردشة وللمهام، max tokens، بحث الويب، جلب الصفحات، ملاحظات التقدم كفقاعات، fallback، caching، Base URL. **Test connection** → شارة ✓ أو ✗ مع السبب. أول تبديل من Demo لنموذج حقيقي يمسح بيانات القصة ويبدأ نظيف |
| **Agent & autonomy** | Supervised / Balanced / Autonomous. جدول الموافقات لكل فئة: Ask / Auto / Block. مهلة الموافقة، أقصى خطوات، عدد المهام المتوازية، حجم السياق |
| **System prompt** | اختيار قالب (Covo / Computer operator / Arabic / Minimal)، محرر كامل + **Preview** (النص النهائي بعد المتغيرات)، Save، Reset to preset، **Extra instructions** تُضاف لأي قالب |
| **Memory** | إضافة/تعديل/حذف حقائق، تشغيل الحفظ التلقائي |
| **Routines** | إضافة (عنوان، وقت، أيام، داخل الدردشة أو كمهمة خلفية)، ▶ تشغيل الآن، تعديل، حذف، تفعيل/إيقاف |
| **Tools & connectors** | تشغيل/إيقاف كل أداة مدمجة، خوادم **MCP** (إضافة command/args/env أو URL، Trusted، Reload، حالة وعدد الأدوات)، **SMTP** للبريد، مهلة الأوامر، الأوامر الممنوعة |
| **Devices** | السماح للوكيل باستخدام هذا السيرفر (بتطبيق سطح المكتب: **This computer**)، مجلد العمل، **Pair a device** → توكن + أوامر Windows/macOS/Linux + روابط تنزيل الملفات، قائمة الأجهزة (متصل/غير متصل) + إلغاء، الجهاز الافتراضي |
| **Notifications** | **Enable** (إشعارات قفل الشاشة — تحتاج HTTPS)، **Test**، أنواع الإشعارات، ساعات الهدوء، ntfy |
| **Security & access** | تغيير كلمة السر (يخرج باقي الجلسات؛ بتطبيق سطح المكتب: **Set password** بدون الكلمة القديمة)، الجلسات + تسجيل خروج، **API tokens** (يظهر مرة وحدة + مثال curl) |
| **Data** | تصدير نسخة JSON، استيراد، مسح الخيط، إعادة الـDemo، مسح كل شيء (مع تأكيد) |
| **Developer** | وضع المطور (يُظهر استدعاءات الأدوات داخل الخيط واستهلاك التوكنات)، Request overrides JSON، محرر الإعدادات الخام، سجل السيرفر |
| **About** | الإصدار، **النسخة** (Desktop / Android / Browser / Server)، السيرفر، النموذج، **Check for updates** (يسأل GitHub فقط لما تضغط)، **Send feedback / Report a bug / Report a security issue** (تفتح صفحة GitHub)، الوثائق القانونية (Terms, Privacy, Trademarks, Licenses تفتح داخل التطبيق) |

## 6) الإشعارات (شاشة القفل)
- **Morning brief** (روتين 07:00 افتراضياً): يرسل إشعار "Morning, Sara. 5 things in progress and 2 that need you." → الضغط يفتح التطبيق على الخيط.

## 7) سيناريو الـDemo (قصة تجريبية خيالية)
شركة وهمية: **Lumen Home** (متجر إضاءة وأثاث أونلاين + 3 معارض). كل الأسماء والأرقام مخترعة.
1. الخيط يبدأ بـ **Morning brief** (5 بنود مع رقاقات حالة).
2. بعد ثانية ونص: **Dubai showroom launch** — 3 فقاعات + بطاقة **$480.00** (Expires in 10 min).
3. **Approve** → شارة **Paid** → "Paid. Next up is the fit-out inspection…" + "Heads-up: the signage vendor moved install…".
4. **Seed round: Atlas Capital** — فقاعتين + بطاقة **Seed deck** + فقاعتين عن ملفات الـdiligence. اقتراح: "Go ahead."
5. "Go ahead." → "Done. 20 of 21." + Prep + بطاقة **Atlas meeting prep**. اقتراح: "Slide 7 feels crowded."
6. → "Moved the cohort table to the appendix… Better?" (والـdeck يتحدث لنسخة 2). اقتراح: "Yes. Email the deck to Layla at Atlas."
7. → "Drafted with the diligence folder link. Send it from you?" + بطاقة **Email** → **Send** → "✓ Sent".
8. اقتراح: "Make me a one-page dashboard…" → موضوع **Lumen Daily** → "Working on it…" → "Lumen Daily is ready…" + بطاقة اللوحة → ضغطها يفتح اللوحة الكاملة.
9. أي رسالة بعدها → شرح أنك بوضع Demo + اقتراح "Restart demo".

## 8) تطبيق سطح المكتب (Windows / macOS / Linux)
| تضغط | يصير |
|---|---|
| تفتح **Covo** أول مرة | نفس الـOnboarding لكن **بدون كلمة سر** (النافذة تدخل تلقائياً) |
| **X** على النافذة | النافذة تختفي والتطبيق يبقى بالـTray (أول مرة يطلع إشعار "Covo is still running") — المهام والروتينات تكمل |
| أيقونة الـTray (كليك) | تفتح النافذة |
| Tray ← **Settings…** | تفتح الإعدادات مباشرة |
| Tray ← **Allow phone access (same Wi‑Fi)** | إذا ما عندك كلمة سر: رسالة "Set a password first" ← زر يفتح Settings ← Security. إذا عندك: تأكيد ← التطبيق يعيد التشغيل ← بالقائمة يطلع **Copy http://192.168.x.x:8787** — افتحه بموبايلك وادخل بكلمة السر |
| Tray ← **Start when I sign in** | يشتغل مخفي بالـTray كل ما تفتح الكمبيوتر |
| Tray ← **Keep running when the window is closed** | إذا شلت الصح، X يسكر التطبيق كامل |
| Tray ← **Open work folder / Open data folder** | يفتح المجلد بمستكشف الملفات |
| Tray ← **Quit Covo** | يوقف الوكيل والسيرفر |
| إشعار من الوكيل والنافذة بالخلفية | إشعار نظام (Windows/macOS) ← الضغط يفتح النافذة على المكان المطلوب |
| رابط خارجي داخل الخيط | ينفتح بمتصفحك الافتراضي؛ صفحة ملف (Open) تنفتح بنافذة Covo ثانية |
| `Ctrl+,` | الإعدادات · `Ctrl+W` يسكر النافذة · `Ctrl+Q` خروج |
